# Focus Timer on React

`Focus Timer on React` — это Pomodoro-приложение на `React` и `Vite` с музыкальным блоком, выбором циклов, сохранением пользовательских настроек и возможностью добавлять собственные треки.

## О проекте

Приложение помогает работать или учиться в режиме фокус-сессий. Внутри одного интерфейса объединены:

- таймер работы и отдыха;
- управление циклами Pomodoro;
- lo-fi музыкальный блок;
- список доступных треков;
- форма добавления новых треков.

Проект хорошо показывает работу с `React`-состоянием, `useEffect`, `useRef`, `localStorage`, `fetch` и локальным `json-server`.

## Основной функционал

- Таймер работы с длительностью `25:00`.
- Таймер отдыха с длительностью `5:00`.
- Переключение между режимами `Work` и `Break`.
- Запуск и остановка таймера одной кнопкой.
- Выбор количества циклов от `1` до `4`.
- Сохранение выбранного количества циклов в `localStorage`.
- Музыкальный блок с фоновым воспроизведением.
- Перемотка трека на `5 секунд` вперёд и назад.
- Регулировка громкости через `range`-слайдер.
- Выпадающий список с доступными треками.
- Выбор трека прямо в интерфейсе.
- Добавление новых треков через форму.
- Сохранение добавленных треков в локальную базу через `json-server`.

## Как работает приложение

После запуска приложение открывается в режиме `Work` со временем `25:00`.

Когда пользователь нажимает кнопку старта:

- начинается обратный отсчёт;
- запускается аудио;
- таймер уменьшает время каждую секунду.

После завершения рабочей сессии:

- режим меняется на `Break`;
- время переключается на `5:00`.

После завершения перерыва:

- увеличивается счётчик завершённых циклов;
- если выбранный лимит достигнут, таймер останавливается;
- если циклы ещё остались, приложение возвращается в режим `Work`.

## Работа с треками

В приложении есть два связанных сценария:

- пользователь может открыть список треков и выбрать любой доступный трек;
- пользователь может открыть форму и добавить новый трек в локальную базу.

Треки загружаются с `json-server` по адресу `http://localhost:3001/trcks`, поэтому для полной работы музыкального блока нужно запускать не только `Vite`, но и локальный сервер с базой данных.

## Хранение данных

В проекте используются два способа хранения данных:

- `localStorage` хранит выбранное количество циклов;
- `db.json5` хранит список музыкальных треков.

Это позволяет:

- не терять настройку циклов после обновления страницы;
- сохранять добавленные треки между запусками локального сервера.

## Ключевые компоненты

### `FocusTimer.jsx`

Главный компонент приложения. Он:

- управляет таймером и режимами работы;
- хранит выбранное количество циклов;
- сохраняет циклы в `localStorage`;
- загружает треки из локальной базы;
- отправляет новые треки в `json-server`;
- управляет воспроизведением аудио через `useRef`;
- открывает список треков и форму добавления.

### `Control.jsx`

Объединяет основной блок управления:

- запуск и остановка таймера;
- перемотка аудио;
- выбор количества циклов;
- управление громкостью.

### `Track.jsx`

Карточка отдельного трека с:

- превью;
- названием;
- длительностью;
- обработчиком выбора трека.

### `Form.jsx`

Форма добавления нового трека. Через неё пользователь вводит:

- название трека;
- длительность;
- затем отправляет данные в локальную базу.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/Canzas-91/Focus-Timer-on-React
```

### 2. Переход в папку проекта

```bash
cd Focus-Timer-on-React
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск frontend

```bash
npm run dev
```

### 5. Запуск локальной базы данных

Во втором терминале:

```bash
npm run server
```

После этого приложение будет доступно через `Vite`, а база треков через `json-server` на `http://localhost:3001/trcks`.
