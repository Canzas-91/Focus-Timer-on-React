# Focus Timer on React

`Focus Timer on React` — это frontend-проект, созданный на `React` и `Vite`. Приложение представляет собой таймер для концентрации в стиле Pomodoro: пользователь может запускать и останавливать таймер, автоматически переключаться между работой и отдыхом, выбирать количество циклов и управлять фоновой музыкой прямо из интерфейса.

## О проекте

Основная идея проекта — сделать простое, понятное и удобное приложение для фокусной работы или учёбы. В одном интерфейсе объединены:

- таймер обратного отсчёта для рабочих и перерывных сессий;
- фоновая lo-fi музыка с базовым управлением воспроизведением.

Этот проект можно использовать как практику по работе с React-компонентами, состоянием, таймерами, `useEffect`, `useRef` и управлением аудио в браузере.

## Основной функционал

- Таймер работы с начальной длительностью `25 минут`.
- Автоматическое переключение из режима `Work` в режим `Break`.
- Таймер перерыва длительностью `5 минут`.
- Запуск и остановка таймера по нажатию на центральную кнопку.
- Выбор количества циклов от `1` до `4`.
- Автоматическое завершение работы после выбранного числа циклов.
- Встроенное воспроизведение фоновой музыки во время работы таймера.
- Перемотка музыки на `5 секунд вперёд`.
- Перемотка музыки на `5 секунд назад`.
- Регулировка громкости через слайдер.

## Как работает приложение

После загрузки приложение стартует в режиме `Work`, а таймер устанавливается на `25:00`.

Когда пользователь запускает таймер:

- начинается обратный отсчёт;
- включается фоновая музыка;
- время уменьшается каждую секунду.

Когда рабочая сессия заканчивается:

- режим меняется с `Work` на `Break`;
- таймер переключается на `5 минут`.

Когда заканчивается перерыв:

- увеличивается количество завершённых циклов;
- если выбранное число циклов уже достигнуто, таймер останавливается;
- если циклы ещё остались, приложение снова возвращается в режим `Work`.

Управление музыкой происходит в этом же интерфейсе:

- левая кнопка перематывает трек на `5 секунд назад`;
- центральная кнопка запускает или останавливает таймер;
- правая кнопка перематывает трек на `5 секунд вперёд`;
- слайдер громкости меняет уровень звука от `0` до `100`.

## Описание компонентов

### `FocusTimer.jsx`

Главный компонент проекта, в котором находится основная логика приложения. Он:

- хранит состояние таймера;
- хранит текущий режим работы;
- хранит выбранное количество циклов;
- отслеживает завершённые циклы;
- управляет воспроизведением аудио через `useRef`;
- запускает и очищает `setInterval`;
- передаёт данные и функции в дочерние компоненты.

### `TimeMode.jsx`

Компонент отвечает за отображение:

- текущего режима `Work` или `Break`;
- оставшегося времени в формате `минуты:секунды`.

### `Control.jsx`

Компонент объединяет основные элементы управления:

- блок музыки;
- кнопки управления;
- выбор количества циклов.

### `Button.jsx`

Переиспользуемый компонент кнопки, который применяется для элементов управления таймером и музыкой.

### `Music.jsx`

Компонент отвечает за музыкальный блок:

- отображает ползунок громкости;
- передаёт изменения громкости в основную логику приложения.

### `CountCycle.jsx`

Компонент с выпадающим списком, который позволяет выбрать количество рабочих циклов.

## Состояния и логика

В приложении используются следующие состояния:

- `time` — хранит оставшееся время в секундах;
- `isRunning` — показывает, запущен ли таймер;
- `mode` — хранит текущий режим: работа или перерыв;
- `cycle` — хранит выбранное количество циклов;
- `completedCycle` — хранит число уже завершённых циклов.

Аудио хранится отдельно через `useRef`, чтобы использовать один и тот же объект `<audio>` между рендерами и управлять им без пересоздания.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <https://github.com/Canzas-91/Focus-Timer-on-React>
```

### 2. Переход в папку проекта

```bash
cd focus-timer-on-react
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск проекта

```bash
npm run dev
```

После этого нужно открыть локальный адрес, который покажет `Vite` в терминале.
